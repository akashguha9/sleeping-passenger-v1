# Prelaunch lawyer review checklist

Required reviews before non-operator use:

- [ ] yfinance terms confirmed for the deployment context.
- [ ] NewsAPI commercial-use tier confirmed if applicable.
- [ ] AI provider (xAI / Anthropic / OpenAI) ToS confirmed.
- [ ] Polymarket / Kalshi public-data redistribution scope confirmed.
- [ ] Privacy notice drafted if any new personal data category is added.
- [ ] Confirm advisory-only language in every operator-facing surface.
- [ ] Confirm no broker execution surface added since last review.
- [ ] Confirm retention policy values match the regulatory regime.
