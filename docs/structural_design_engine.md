# Structural Design Engine

Origin: this layer converts the San Siro vs Vélodrome reflection into a deterministic structural scoring module for the MVP diagnostics pipeline.

Core equation:

`Architecture = ObjectiveFunction -> StructuralDecision -> EmergentExperience`

San Siro maps to pressure systems:
- compression
- density
- vertical stacking
- exposed structure
- urgency and containment
- high-friction decision rooms

Vélodrome maps to flow systems:
- continuity
- curvature
- channeling
- adaptive routing
- acoustic amplification
- pipeline coherence

The engine adds:
- Pressure Field Engine
- Flow Field Engine
- Historical Layer Separator
- Load Path Mapper
- Emotional Geometry Analyzer
- Structural Expression Classifier
- Atmosphere Equation Layer

Why origin is not current identity:
- the current operating form is a weighted combination of original intent, later expansions, renovations, present use, and evolving constraints

Why load path reveals hidden strategy:
- the clearest system objective often appears in how force, stress, queues, or attention are transferred and contained, not in surface presentation

How this maps to MVP diagnostics:
- `PRESSURE_FIELD` is useful when the system needs urgency, focus, gate enforcement, or high-conviction action
- `FLOW_FIELD` is useful when the system needs discovery, routing, smooth movement, or signal propagation
- `HYBRID_FIELD` means both forms are coherent
- `FRAGMENTED_FIELD` warns that pressure and flow are both weakly organized
- `LOW_STRUCTURE` means the architecture is too weak to over-trust
- `POLICY_SUPPRESSED` means policy veto outranks structural attractiveness

Formulas:

```text
PressureScore =
0.20*Density
+ 0.15*Verticality
+ 0.15*Proximity
+ 0.15*AcousticContainment
+ 0.15*StructuralExposure
+ 0.20*FocusCompression

FlowScore =
0.20*Continuity
+ 0.15*Curvature
+ 0.15*Coverage
+ 0.15*EnvironmentalFit
+ 0.20*ChannelingEfficiency
+ 0.15*AdaptiveUse

CurrentIdentityScore =
0.15*OriginalIntentFit
+ 0.20*ExpansionImpact
+ 0.25*RenovationImpact
+ 0.25*CurrentUsageFit
+ 0.15*ConstraintAdaptation

LoadPathCoherence =
InputForceClarity * TransferNodeReliability * GroundingQuality * FailureContainment

EmotionalGeometryScore =
0.18*GeometryIntensity
+ 0.18*DensityEffect
+ 0.14*VisibilityEffect
+ 0.18*AcousticEffect
+ 0.14*MovementEffect
+ 0.18*HistoricalMemoryEffect

AtmosphereScore =
PhysicalFormScore * OccupancyProxy * AcousticProxy * MemoryProxy

InvestableStructuralSignal =
DetectedSignal
* StructuralCoherence
* LoadPathCoherence
* AtmosphereScore
* ValidationScore
* DurabilityScore
* ExecutionSurvivability
```

Limitations:
- currently proxy-based
- not using real acoustic, crowd, or market microstructure feeds
- must not override policy gates
- remains advisory and diagnostic only
