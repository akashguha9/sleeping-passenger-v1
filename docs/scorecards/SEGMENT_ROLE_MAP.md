# Segment Role Map

> Human-readable companion to `runtime/release/segment_role_scorecard.json`.
> Each segment names the role it plays in *this* MVP, the criteria it is
> graded against, and what would lift it.  Internal doc only — the
> football mental model lives in `ROLE_FIT_SCORING_MODEL.md`; the UI
> never speaks in role-fit language.

For the formulas, see `ROLE_FIT_SCORING_MODEL.md`.
For the live numbers, see `SEGMENT_ROLE_SCORECARD.md` (regenerated by
`python scripts/segment_role_scorecard.py --json … --markdown …`).

---

## How to read this file

For each segment we list:

- **Role name** — a one-line label for what this segment is *for*.
- **Role description** — the failure it is supposed to prevent or the
  capability it is supposed to deliver.
- **Target relevance `T_s`** — 1 if we are targeting this role this
  year, 0 if explicitly NOT_TARGETED, in between if partially targeted.
- **Absolute ceiling** — the hard cap on `A_s` and why.
- **Role-fit ceiling** — what would let `R_s` reach 10/10.

We deliberately keep this file short. The detailed criteria, weights,
and per-criterion evidence live alongside the script and inside the
generated `SEGMENT_ROLE_SCORECARD.md`.
