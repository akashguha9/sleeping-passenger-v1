# Calibration Corpus Schema

**Sprint:** proof_loop_hardening_sprint, Phase 2.

This file documents the canonical row shape consumed by
`scripts.calibration_report` and produced by
`scripts.curate_calibration_corpus`.  It is the *single* reference for
what counts as a calibratable row.

> **EMPTY by default.**  This directory contains a *template* CSV
> (`paper_trade_ledger_template.csv`) marked DEMO_ONLY / EMPTY.  No
> real outcomes ship in the repo.  The canonical materialised corpus
> lives at `runtime/release/calibration_corpus.json` and is built by
> the curate script from local SQLite.

## Calibratability rule

A row is calibratable if and only if **all** of the following hold:

```
is_real_outcome_i = True
is_fixture_i      = False
is_mock_i         = False
is_synthetic_i    = False
p_i in [0, 1]
y_i in {0, 1}
target_event_definition_i is not null
prediction_horizon_days_i > 0
exit/outcome timestamp exists
advisory_status_i = "ADVISORY_ONLY"
execution_gate_i  = "LOCKED"
broker_api_called_i = False
ai_execution_count_i = 0
```

Let `N_real = Σ_i 1[calibratable_i]`.

| `N_real` | `calibration_status` |
|---|---|
| `0` | `INSUFFICIENT_EVIDENCE` |
| `[1, 20)` | `TOO_FEW_OUTCOMES` |
| `[20, 200)` | `MEASURABLE_WITH_WARNING` |
| `≥ 200` | `MEASURED` |

Predictive validity is *never* claimed unless `N_real ≥ 200` **and**
Brier ≤ 0.25 **and** ECE ≤ 0.10 **and** MCE ≤ 0.25.

## Provenance markers

Every artifact generated by the curate script is stamped with exactly
one of:

- `REAL` — sourced from canonical SQLite reconciliations.
- `EMPTY` — no rows exist yet (default state of this repo).
- `FIXTURE` — test fixture; never counted toward `N_real`.
- `SYNTHETIC` — generated for unit tests; never counted toward `N_real`.
- `DEMO_ONLY` — shaped for screenshots / demos; never counted.
- `INSUFFICIENT_EVIDENCE` — math layer reports null metrics.

Files under `data/calibration_corpus/` are `EMPTY` / `DEMO_ONLY`
templates.  The materialised corpus lives at
`runtime/release/calibration_corpus.json`.

## Hard rules

- **No fabrication.**  The curate script never invents `p_i` or `y_i`.
- **No broker / order / fill / position / execution row** is created.
- **No mock or fallback row** is silently promoted to real.
- **JSONL is never canonical.**  SQLite is the source of truth.
